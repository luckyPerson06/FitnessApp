# Фитнес-студия — KVETKA

## 📋 О проекте

Полнофункциональное веб-приложение для управления фитнес-студией. Состоит из Spring Boot backend API и React SPA frontend. Автоматизирует работу с клиентами, тренерами, абонементами, расписанием тренировок и посещаемостью.

## 🏗️ Функциональность

### 👥 Управление клиентами
- Регистрация с двухшаговой формой и клиентской валидацией
- Профили клиентов с историей посещений
- Привязка и управление абонементами (ManyToMany)
- Поиск и фильтрация по ФИО, телефону, email, статусу
- Административная панель со списком клиентов

### 👨‍🏫 Управление тренерами
- Профили с фото, описанием и статусами (активен/в отпуске/на испытательном сроке)
- Специализации по типам тренировок (ManyToMany)
- Автоматическая проверка занятости при создании тренировок
- Отображение на странице расписания и карточках направлений

### 📅 Расписание тренировок
- Недельный календарь с навигацией (4 недели)
- Создание тренировок с проверкой пересечений по времени и дате
- Визуальная индикация занятости (свободно → заполнено)
- Автоматическое удаление тренировок старше 1 месяца
- Прошедшие и заполненные тренировки затемняются
- Фильтрация по тренеру и типу тренировки

### 🧘 Направления
- Каталог типов тренировок с иконками, описанием, противопоказаниями
- Уровни сложности со звёздами (начальный/средний/продвинутый/для всех)
- Поиск по названию и описанию с подсветкой совпадений
- Модальное окно с полной информацией: тренеры, ближайшие занятия, преимущества
- Админ: создание, редактирование (включая назначение тренеров), деактивация, удаление

### 🎟️ Абонементы
- Два типа: лимитированный (ограничение по занятиям) и безлимитный
- Привязка к направлениям тренировок (ManyToMany)
- Фильтрация по направлениям через боковую панель
- Карточки с ценой, сроком действия, списком направлений
- Админ: полный CRUD с валидацией

### 📍 Информация о клубе
- Редактируемая страница «О клубе» с контактами и картой
- Админ: inline-редактирование всех полей

### 🔐 Аутентификация и авторизация
- JWT-токены (генерация при логине, прикрепление ко всем запросам)
- Две роли: CLIENT и ADMIN
- Защита эндпоинтов на бэке (`@PreAuthorize`)
- Скрытие/показ элементов интерфейса по роли на фронте
- Автоматический редирект при истечении токена

## 🛠️ Технический стек

### Backend
- **Java 17**, **Spring Boot 3.3.5**
- **Spring Security** + JWT (io.jsonwebtoken)
- **Spring Data JPA** + Hibernate + PostgreSQL
- **MapStruct** для маппинга Entity ↔ DTO
- **Flyway** для миграций БД
- **AOP** для логирования вызовов сервисов/контроллеров
- **In-memory кэш** на ConcurrentHashMap с TTL по регионам
- **Swagger/OpenAPI** для документации API

### Frontend
- **React 18** (функциональные компоненты + хуки)
- **React Router v6** (SPA-роутинг)
- **Axios** с перехватчиками (JWT, обработка 401)
- **CSS-in-JS** (inline styles в стилистике приложения)
- Кастомные иконки SVG, Google Maps API

### Модель данных
- **8 сущностей**: User, Client, Trainer, WorkoutType, WorkoutSession, Subscription, Visit, ClubInfo
- Связи: OneToMany (Trainer→Sessions, Client→Visits), ManyToMany (Trainer↔WorkoutType, Subscription↔WorkoutType, Client↔Subscription)
- Оптимистичные блокировки (`@Version`)
- Индексы по внешним ключам и поисковым полям
- JSONB-поля для benefits и socialLinks

### Кэширование
- 5 регионов с раздельными TTL (sessions=30min, types=60min, subscriptions=60min, trainers=60min, clubInfo=120min)
- Составной ключ (регион + идентификатор)
- Автоматическая инвалидация при CUD-операциях
- Точечное вытеснение (по дате, по тренеру)
